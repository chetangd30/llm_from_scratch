# Phi-3 First Text Generation

This project demonstrates how to run Microsoft's
Phi-3 Mini 4K Instruct model using Hugging Face
Transformers in Google Colab.

## Features
- Load Phi-3 model
- Use GPU acceleration (T4)
- Generate text using the pipeline API
- Chat-style prompting

## Technologies
- Python
- Hugging Face Transformers
- PyTorch
- Google Colab
